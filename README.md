# TechPulse AI 🚀

TechPulse AI is an AI-powered IT news platform that automatically collects the latest technology news, processes articles using AI, categorizes them, and displays them through a modern web application.

---

##  Features

- Automated IT news collection using NewsAPI
- AI-powered article categorization and summarization
- Workflow automation with n8n
- MongoDB database integration
- FastAPI backend API
- React frontend
- Ollama local AI model integration
- Search and category filtering

---

##  Tech Stack

- Frontend: React + Vite
- Backend: FastAPI
- Database: MongoDB
- Automation: n8n
- AI Processing: Ollama + Llama 3
- Language: Python & JavaScript
